# T-0003 — port sqlite3_strglob and sqlite3_strlike

## 状态
queued

## 前置
- T-0002 完成 (malloc family)

## 目标
实现 src/util/pattern.rs:
- sqlite3_strglob(const char *zGlob, const char *zStr) -> i32
- sqlite3_strlike(const char *zPattern, const char *zStr, u32 esc) -> i32

## 行为
- 支持通配符 * 和 ?
- strlike 支持 ESCAPE 字符
- 行为与 C 版 byte-for-byte 一致
- 大小写敏感性默认
- ESCAPE 0 行为

## 测试
12+ 用例对比 C 行为:
- 'a*' 匹配 'abc' 返回 SQLITE_OK(0)
- 不匹配返回 SQLITE_NOMATCH(27)
- 空 pattern 匹配空串
- ? 匹配单字符
- ESCAPE 字符转义 *
- 中间穿插 . 等
